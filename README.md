# AI Home

AI Home 是一个可观察、可介入的 2D 家庭模拟：俯瞰爸爸、妈妈、奶奶、乐乐和机器人「小暖」的一天，也可以随时接管其中一个角色。
它参考了 AI Town「世界模拟 / 角色行为 / 大模型对话分离」的思路；房屋布局、角色、界面和画面都是独立设计的（Canvas 程序绘制，没有外部素材）。

## 启动

需要 Node.js ≥ 20（开发时用的是 24.22.3）。

```bash
npm install
npm run dev          # 同时启动模型代理服务(:8787)和前端(:5173)，打开 http://localhost:5173
```

生产模式：

```bash
npm run build && npm start   # 打开 http://127.0.0.1:8787
```

### 配置大模型（可选）

复制 `.env.example` 为 `.env`，填写 OpenAI 兼容的服务：

```
LLM_API_KEY=sk-...
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

- 不配置密钥时自动进入**演示模式**：用预置对白和规则解析器跑通全部场景，界面右上角标明「演示模式」。
- 也可以在界面右上角的「⚙ API 设置」窗口里临时填写服务地址、模型和密钥，并测试连接。界面填写的密钥只保存在本地 Node 进程的内存里，不写文件，也不回传给浏览器。

## 测试

```bash
npm test             # 演示模式下的验收场景（无需密钥）
npm run typecheck
# 真实模型验证：先用密钥启动服务，再运行
AIHOME_API=http://127.0.0.1:8787/api npx vitest run tests/live.test.ts
```

## 目录

| `src/sim/world.ts` | 世界模拟：游戏时钟（每步 10 秒）、作息与午饭、活动开始/结束事件、家具状态、移动与碰撞、对话、手动接管 |
| `src/sim/robot.ts` | 机器人：有限视野感知、短期/长期记忆、待办队列与优先级、巡视、找人提醒、确认无人后关灯、理解临时交代 |
| `src/sim/memory.ts` | 记忆容量与淘汰规则 |
| `src/sim/tasks.ts` | 任务结构、校验、确认话术 |

## 设计要点

- **职责划分**：模拟器负责时间、位置、碰撞、家具状态和任务状态；大模型只负责生成台词和把临时交代解析成结构化 JSON。模型请求是异步的，等待期间时钟和其他角色照常运行。结果返回时再检查一次条件：说话双方是否还在附近、没被墙隔开；任务能否执行、是否重复、「吃完饭」是否已经过去。
- **户型**：参照一张竖版户型图设计。最上面是种满绿植的阳台；左列从上到下是爸爸的工作室、餐厅（长餐桌，下面一排咖啡机，和客厅相通）、厨房和乐乐的房间；中间是大客厅（电视、L 形沙发、钢琴、摇椅、书柜）；右列从上到下是主卧（爸爸妈妈）、奶奶房、浴室和影音室（大电视、沙发）；影音室左边是储物间（机器人的充电座），最下面是玄关走廊。地图比屏幕高，可以缩放、上下滚动，并自动跟随选中的角色。
- **画面风格**：参照同一张图：奶油色方砖地面带细缝、浅橙色砖块墙、白色门洞、深色木地板的工作室、粉白的儿童房、蓝色瓷砖的浴室；页面也用同样的砖块边框和方格底纹。
- **可交互的家具**：除了灶台、书架、电视、电脑、洗衣机、餐桌、床和灯，还有钢琴（琴声音符）、小圆凳（坐着听琴）、冰箱（开门取零食）、一排咖啡机（冒热气）、藤椅（阳台喝茶）、穿衣镜、洗手台、浴缸（泡澡冒泡）、收音机（听戏曲）和影音室的大电视（看电影）。每个人的性格描述里写了他们爱用哪些家具，空闲时按偏好和时间选择。
- **阳台浇花**：阳台有四组盆栽，每组单独计算水分，大约 14 小时从浇透到干透。水分 ≥ 60% 叶子翠绿，35%–60% 有点蔫，低于 35% 发黄；浇水后立刻回到 100%，叶子变回绿色并挂上水珠，每组下面有一条水分条。家人看到叶子发黄更愿意去浇；你接管任何人都可以点盆栽浇水；也可以让小暖去浇；小暖巡视时看见叶子发黄也会自己安排浇水。演示开局有两组已经发黄。
- **作息**：12:00 开饭，家人从各自位置走到自己的座位；每人吃满 25 分钟（最晚 13:10）后发出「午饭结束」事件（`activity_end / lunch`）。21:30 后回各自的床睡觉。所有活动都会发出开始和结束事件。
- **做饭与家务**：妈妈只在三餐前做饭（早饭 07:00–07:40、午饭 11:15–11:58、晚饭 17:20–18:10）。到了这几个时间，她会放下手头的事去灶台，其余时间不会把做饭当作空闲活动。自主洗衣服至少隔 3 小时一次。
- **交流规则**：距离 ≤ 4 格，并且双向视线都不被墙挡住。每句一到两句话，对白气泡显示在头顶。用户接管的角色说的话走同一套规则。
- **机器人感知**：开局知道静态地图（墙、门、房间、交互点和预先算好的观察点）。人物位置、灯的开关、房间里有没有人，都要在半径 7 格、会被墙遮挡的视野里现场看到。
- **记忆**：
  - 短期记忆 16 条：同一对象在同一房间只留最新一条，满了淘汰最旧的。
  - 长期记忆 10 条：📌 固定安排不淘汰；满了淘汰强度最低的，强度相同时淘汰最久没更新的。
  - 家人常去的地方由观察次数自动更新。
- **机器人能做的事**：开灯/关灯（可带「没人才关」条件）、没人看时关客厅或影音室的电视、启动洗衣机、给阳台每一组缺水的盆栽浇水、到点提醒某人。午饭时它会先去餐厅看看大家。
- **优先级**：有时间要求的提醒 > 普通家务 > 巡视。巡视会被到期任务打断，任务做完后继续。房间里有人时，关灯任务进入「稍后再查」（20 分钟后再来）。
- **巡视**：选最久没检查的房间作目的地，用 BFS 在可通行格子上规划四方向路线。每个房间有一组预先算好的巡视点（视野半径 4 格全覆盖；走廊这类狭长房间额外加上两端，并从近的一端扫到另一端），要走遍全部巡视点才算巡视完。只是路过时，看清 95% 的格子才记为「检查过」。
- **随手关灯**：机器人看清某个房间后，如果屋里没人、灯却亮着，就自己加一条「关灯（无人时）」家务；执行前会再确认一次无人。如果有人交代过开这盏灯（还没执行，或两小时内刚开的），就不会擅自关。

## 演示怎么看

1. 打开后时钟从 11:30 开始。家人各自在书房、厨房、儿童房、客厅活动。地图右上角可以切换「全屋」或「适应宽度」，勾选「跟随」后视野会跟着选中的角色。
2. 点「▶ 一键演示：爸爸交代关灯」，或在「家庭成员」里接管爸爸：点地板走到小暖身边（小暖会停下等你），输入「吃完饭帮我看看书房的灯，没人就关掉」。待办里会出现「关书房的灯（无人时）」。然后释放控制。
3. 午饭结束后，小暖先按最近一次看到奶奶的位置去找她并提醒吃药，再去书房确认无人后关灯。
4. 地图上方的「🛋 家具状态」按钮可以打开或关闭家具状态窗口。窗口按房间列出全部可交互家具，每件有实时状态和标签（使用中 / 开着 / 需要照料 / 空闲）；可以只看「有动静的」，盆栽带水分条。点任意一行，地图会滚动到那件家具并闪烁高亮；拖动标题栏可以移动窗口。
5. 勾选「👁 机器人视角」看墙怎么挡住视线；点「⏩ 快进到夜间」看家人回床睡觉。
